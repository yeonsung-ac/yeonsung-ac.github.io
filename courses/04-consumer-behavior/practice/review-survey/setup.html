최초 1회 설정

조사에 사용할 Firebase를 연결하세요.

배포할 때는 public/config.js를 편집하는 방법을 권장합니다. 아래 설정은 현재 브라우저에만 저장되며 다른 학생의 브라우저에 전달되지 않습니다.

  1. Firebase Console에서 웹 앱을 추가하고 웹 설정 객체를 복사합니다.
  2. Authentication에서 익명 로그인과 이메일/비밀번호를 사용 설정합니다. 관리자 계정을 만들고 UID를 확인합니다.
  3. Firestore에 reviewSurveyAdmins/{관리자 UID} 문서를 만들고 role: "admin" 필드를 넣습니다. 이 문서는 Firebase Console에서만 생성합니다.
  4. 프로젝트의 firestore.rules를 게시합니다. 기존 프로젝트 규칙을 덮어쓰지 않도록 README의 병합 안내를 확인하세요.
  5. 관리자로 로그인하여 목표 인원과 참여코드를 준비한 후 조사를 시작합니다.

Firebase의 공개 웹 설정만 입력하세요. 서비스 계정 JSON, 개인 비밀번호, 비밀키는 넣지 마세요. 입력한 Firebase 프로젝트가 맞는지 반드시 확인하세요.
