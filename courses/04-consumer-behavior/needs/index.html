분류 기준과 계산식 확인하기

수업에서 제시된 ‘니즈의 분류’를 바탕으로 만든 학습용 문항입니다. 각 니즈에 동일하게 3개 문항을 배정하고, 0~4점 응답을 같은 가중치로 계산합니다.

니즈 점수 = (해당 문항의 점수 합 ÷ 응답한 문항 수 ÷ 4) × 100
소수점은 반올림합니다. 미응답은 0점으로 처리하지 않으며, 최종 해석은 9개 응답 후 제공합니다. 세 점수는 독립적이어서 합이 100일 필요가 없습니다.

  • 기능적: 1, 4, 7번 문항
  • 상징적: 2, 5, 8번 문항
  • 쾌락적: 3, 6, 9번 문항

실제 구매 이유는 여러 니즈에 걸칠 수 있습니다. 예를 들어 ‘휴식’도 피로 회복이 목적이면 기능적, 즐거운 경험이 목적이면 쾌락적으로 해석할 수 있습니다. 이 앱은 학습을 위해 질문마다 대표 니즈 하나를 연결했습니다.

제품·상황 텍스트는 해석의 맥락이며 자동 분석하지 않습니다. 점수는 오직 선택한 응답으로 계산됩니다. 응답은 별도로 저장하거나 서버로 전송하지 않습니다.

프로그래밍 학습 포인트와 확인 문제

변수는 제품과 응답을 저장하고, 배열·객체는 질문과 분류를 묶습니다. 이벤트가 응답 변경을 감지하면 함수가 다시 계산하고, 조건문이 미응답·동점·0점에 맞는 문장을 보여줍니다.

const answered = values.filter(v => v !== null);
const score = answered.length === 0 ? 0
  : Math.round(
      answered.reduce((sum, v) => sum + v, 0)
      / answered.length / 4 * 100
    );

직접 확인: 모두 4점을 선택하면 세 점수가 각각 100인가요? 모두 0점이면 어떤 문장이 나오나요? 기능적 문항 하나만 0→4로 바꾸면 다른 두 니즈는 유지되나요?

확장 과제: 질문 하나가 두 니즈에 걸치는 사례를 찾고, 분류나 가중치를 어떻게 바꿀지 근거를 제시하세요.
