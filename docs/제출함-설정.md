# 과제 제출함 설정 가이드

학생이 수업에서 만든 파일(코드·문서·이미지·음원)을 올리면
**본인과 교수만** 볼 수 있는 제출함입니다. 주소는 `/submit/` 입니다.

게시판(`/board/`)과 같은 Firebase 프로젝트를 쓰지만 코드는 완전히 따로 돌아갑니다.
게시판이 멈춰도 제출함은 영향받지 않습니다.

| 동작 | 학생 | 교수 |
| --- | --- | --- |
| 파일 올리기 | ✅ | ✅ |
| 목록·내려받기 | 본인 것만 | 전체 |
| 삭제 | 본인 것만 | 전체 |
| 보관 용량·요금 안내 | 안 보임 | 보임 |

---

## 1. Storage 켜기 (요금제 전환 필요)

파일 실물은 Firebase의 **Cloud Storage**에 보관합니다.
무료(Spark) 요금제에서는 이 기능을 못 켜기 때문에 **Blaze(종량제)로 올려야 합니다.**

1. https://console.firebase.google.com → `yeonsung-ac` 프로젝트
2. 왼쪽 **데이터베이스 및 스토리지 > Storage** → **시작하기**
3. 업그레이드를 요구하면 결제 계정을 연결합니다
4. 버킷 위치는 **`asia-northeast3 (서울)`**

> **요금이 실제로 나오나요?**
> 무료 할당량이 저장 5GB · 일일 다운로드 1GB · 일일 업로드 2만 건입니다.
> 코드 파일과 MP3 위주라면 학기 내내 써도 이 안에 들어옵니다. 그래도 카드는 등록해야 합니다.
>
> **안전장치를 꼭 걸어 두세요.** Google Cloud 콘솔 > 결제 > 예산 및 알림에서
> 월 1,000원 초과 시 메일이 오도록 설정하면 예상치 못한 청구를 막을 수 있습니다.
>
> 제출함 화면 위쪽에는 현재 보관 용량이 **빨간 상자**로 항상 표시됩니다(교수에게만).
> 5GB에 가까워지면 상자가 빨갛게 반전됩니다.

## 2. 교수 계정

교수 판별은 **구글 로그인 이메일**로 합니다. 콘솔에서 UID를 찾아올 필요가 없습니다.
현재 등록된 주소는 `dasahee@yeonsung.ac.kr` 하나입니다.
이 주소로 로그인하면 모든 제출물과 학생 비밀글이 보입니다.

계정을 바꾸거나 더하려면 **세 곳을 같은 목록으로** 맞춥니다.

| 위치 | 무엇 |
| --- | --- |
| [`professor.js`](../professor.js) 의 `PROFESSOR_EMAILS` | 화면에 전체 목록을 보여줄지 판단 (게시판 비밀글도 이 값을 씀) |
| [`firestore.rules`](../firestore.rules) 의 `isProfessor()` | 목록 데이터 읽기 권한 |
| [`storage.rules`](../storage.rules) 의 `isProfessor()` | 파일 내려받기 권한 |

> `professor.js`만 고치면 화면에는 전체 목록이 뜨는 것처럼 보여도 서버가 막아
> 아무것도 안 나옵니다. 규칙 두 파일도 함께 고치고 콘솔에 다시 게시해야 합니다.
>
> 학교 계정과 개인 지메일을 번갈아 쓰신다면 두 주소를 모두 적어 두세요.
> 어느 쪽으로 로그인해도 교수로 인정됩니다.

## 3. 규칙 게시

**Firestore 규칙** — 콘솔 **Firestore Database > 규칙** 탭에
저장소의 [`firestore.rules`](../firestore.rules) 내용을 통째로 붙여넣고 **게시**

**Storage 규칙** — 콘솔 **Storage > 규칙** 탭에
저장소의 [`storage.rules`](../storage.rules) 내용을 통째로 붙여넣고 **게시**

두 파일 모두 UID를 바꾼 뒤에 붙여넣어야 합니다.

## 과제 목록 바꾸기

[`submit/settings.js`](../submit/settings.js) 한 파일만 고치면 됩니다.

```js
export const ASSIGNMENTS = [
  "1차 과제",
  "2차 과제",
  "3차 과제",
  "기말 프로젝트",
];
```

이름을 바꾸거나 줄을 더하고 `main` 브랜치에 push 하면 몇 분 안에 반영됩니다.
**규칙 파일은 건드리지 않아도 됩니다** — 과제 이름은 글자 수만 검사하도록 해 두었습니다.

이미 제출된 파일의 과제 이름은 그대로 남습니다. 목록에서 옛 이름이 보이면
그 이름의 과제가 지워진 것이니, 거르기 목록에 없어도 검색으로 찾을 수 있습니다.

## 파일 크기 제한 바꾸기

`submit/settings.js` 의 `MAX_FILE_MB` 와 `storage.rules` 의
`50 * 1024 * 1024` 를 **같은 값으로** 고칩니다.
한쪽만 고치면 브라우저는 통과시키는데 서버가 거절하는 상태가 됩니다.

## 파일 정리

학기가 끝나면 제출물을 내려받아 두고 삭제하세요. 보관 용량이 줄어 요금 위험이 사라집니다.
콘솔 **Storage > 파일** 탭에서 `submissions/` 폴더를 통째로 지워도 되지만,
그러면 Firestore의 목록만 남아 "내려받지 못했습니다" 오류가 납니다.
**제출함 화면에서 삭제**하면 파일과 목록이 함께 지워집니다.
