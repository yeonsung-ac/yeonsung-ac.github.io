# 게시판 설정 가이드

홈페이지는 GitHub Pages(정적 호스팅)에 올라갑니다. 서버가 없기 때문에
게시판의 글 저장과 로그인은 **Firebase**(구글)가 담당합니다.

아래 4단계를 한 번만 해 두면 됩니다. 설정 전에도 홈페이지는 정상 동작하고,
게시판에만 "설정이 아직 끝나지 않았습니다" 안내가 표시됩니다.

---

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 접속 → **프로젝트 추가**
2. 프로젝트 이름 입력 (예: `yeonsung-ac-board`)
3. Google 애널리틱스는 꺼도 됩니다 → **프로젝트 만들기**

> **두 사이트가 Firebase 프로젝트 하나를 함께 씁니다.**
> 게시판(`/board/`)과 부트캠프 신청(`/YouthLeap/`) 모두 이 프로젝트 하나로 동작합니다.
> 이미 만들어 두었다면 새로 만들지 말고 그 프로젝트를 그대로 쓰세요.

## 2. 구글 로그인 켜기

1. 왼쪽 메뉴 **빌드 > Authentication** → **시작하기**
2. **Sign-in method** 탭 → **Google** 선택 → **사용 설정** → 저장
3. **Settings > 승인된 도메인**에 아래가 있는지 확인하고, 없으면 추가합니다.
   - `localhost` (내 컴퓨터에서 테스트할 때)
   - `yeonsung-ac.github.io` (실제 사이트)

> 이 도메인 등록을 빼먹으면 실제 사이트에서 로그인 팝업이
> `auth/unauthorized-domain` 오류로 막힙니다.

## 3. Firestore 데이터베이스 만들기

1. 왼쪽 메뉴 **빌드 > Firestore Database** → **데이터베이스 만들기**
2. 위치는 `asia-northeast3 (서울)` 권장
3. 모드는 아무거나 골라도 됩니다 (다음 단계에서 규칙을 덮어씁니다)
4. **규칙(Rules)** 탭 → 저장소의 [`firestore.rules`](../firestore.rules) 내용을 통째로 붙여넣고 **게시**

규칙 요약:

| 동작 | 권한 |
| --- | --- |
| 글 읽기 | 누구나 |
| 글 쓰기 | 구글 로그인한 사용자 |
| 글 수정·삭제 | 본인이 쓴 글만 |

> `firestore.rules`에는 게시판(`posts`)과 부트캠프 신청(`applications`) 규칙이
> **이미 함께 들어 있습니다.** 파일 전체를 그대로 붙여넣으세요.
> 일부만 붙여넣으면 나머지 한쪽이 동작하지 않습니다.
> (YouthLeap 저장소의 `firestore.rules`와 내용이 같습니다. 아무 쪽이나 하나만 쓰면 됩니다.)

## 4. 설정값 넣기

Firebase 콘솔 **프로젝트 설정(⚙️) > 내 앱 > 웹 앱 추가(`</>`)** 를 누르면
`firebaseConfig` 값이 나옵니다. 그 값을 [`board/firebase-config.js`](../board/firebase-config.js)에 붙여넣으세요.

```js
export const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "yeonsung-ac-board.firebaseapp.com",
  projectId: "yeonsung-ac-board",
  storageBucket: "yeonsung-ac-board.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
};
```

수정한 뒤 `main` 브랜치에 push 하면 몇 분 안에 사이트에 반영됩니다.

> **참고:** 이 값들은 브라우저에 노출되는 공개 식별자라 숨겨야 하는 비밀번호가 아닙니다.
> 실제 보안은 3단계의 Firestore 규칙이 담당합니다.

## 화면 구성

게시판은 페이지 한 장으로 되어 있고, 주소 뒤 해시로 화면이 바뀝니다.

| 주소 | 화면 |
| --- | --- |
| `/board/` | 글 목록 · 분류 필터 · 검색 |
| `/board/#new` | 새 글 쓰기 (로그인 필요) |
| `/board/#p=글ID` | 글 상세 · 수정 · 삭제 (본인 글만) |

분류는 **자유 · 질문 · 후기 · 공지** 네 가지입니다.
분류를 바꾸려면 `board/board.js` 위쪽의 `CATEGORIES` 와 `firestore.rules`의
`category in [...]` 목록을 함께 고쳐야 합니다.

## 글 관리

Firebase 콘솔 **Firestore Database > 데이터** 탭의 `posts` 컬렉션에서
모든 글을 확인하고 지울 수 있습니다. 부적절한 글은 여기서 바로 삭제하면 됩니다.
