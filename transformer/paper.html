왜 √dk 로 나누는가

dk 가 커지면 내적 q·k 의 크기가 함께 커집니다. 성분이 서로 독립이고 평균 0, 분산 1이라면 내적의 분산은 dk 가 됩니다. 값이 커진 채로 softmax 에 들어가면 한 곳만 1에 가까워지고 기울기가 거의 0인 영역으로 밀립니다. 그래서 표준편차 √dk 로 되돌려 놓습니다. (논문 각주 4)

가산 어텐션 대신 내적을 쓴 이유

이론적 복잡도는 비슷하지만, 내적은 행렬 곱 한 번으로 끝나 실제 장비에서 훨씬 빠르고 메모리 효율이 좋습니다.

순환신경망은 순차 연산이 O(n) 이라 문장 안에서 병렬화가 되지 않고, 양 끝 단어 사이 경로도 n 단계입니다. 셀프 어텐션은 한 번에 모든 쌍을 잇기 때문에 경로가 상수이고 전부 병렬로 계산됩니다. 대신 길이의 제곱에 비례하는 계산량을 치릅니다 — 오늘날 긴 문맥이 비싼 이유가 여기 있습니다.

더 볼 것

이 논문에서 갈라져 나온 다른 쪽들입니다.

숫자가 된 낱말 → Input Embedding 이 만들어 내는 벡터를 진짜 모형에서 꺼내 봅니다. 유사도·2차원 지도·벡터 셈까지 전부 실측값입니다. 트랜스포머 탐험대 → 같은 구조를 초등학생용으로. 수업에서 도입부로 쓰기 좋습니다.

논문 뒤에 달라진 것

아래는 논문에는 없는 내용입니다. 오늘의 모형과 그림을 비교할 때 필요해 덧붙입니다.

  • Post-LN → Pre-LN — 논문은 LayerNorm(x + Sublayer(x)) 이지만, 이후 대부분은 정규화를 서브층 앞에 두어 깊은 모형의 학습을 안정시킵니다.
  • 인코더·디코더 → 디코더만 — GPT 계열은 오른쪽 기둥만 씁니다. 번역이 아니라 이어쓰기가 목적이라 인코더가 필요 없습니다. BERT 는 반대로 왼쪽만 씁니다.
  • 절대 위치 → 상대 위치 — 정현파 위치 인코딩 대신 RoPE, ALiBi 같은 방식이 널리 쓰입니다.
  • ReLU → GELU · SwiGLU, LayerNorm → RMSNorm 등 세부 부품이 바뀌었습니다.
  • 그러나 가운데 뼈대 — 어텐션으로 위치를 잇고, 위치별 FFN 을 통과시키고, 잔차로 쌓는다 — 는 그대로입니다.
